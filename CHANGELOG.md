# Changelog

All notable changes to Tickt are documented here.

## [1.0.0]

First public release candidate. Tickt includes the core timer state machine, local SQLite
history, daily statistics, XDG configuration, a Ratatui dashboard, and a fast statically linked
Linux x86_64 release archive validated across representative Debian, Ubuntu, Arch, Fedora,
openSUSE, Rocky Linux, and Alpine containers. The GitHub release has not been published from
this checkout yet.
