# Changelog

All notable changes to Tickt are documented here.

## [1.1.0]

Performance-focused maintenance release. Adds an in-memory interactive statistics accumulator,
dirty-only terminal redraws, reproducible large-history and SQLite write-latency benchmarks, and
expanded regression coverage. The formal release body is maintained in
`release-notes/v1.1.0.txt`.

## [1.0.0]

First public release. Tickt includes the core timer state machine, local SQLite
history, daily statistics, XDG configuration, a Ratatui dashboard, and a fast statically linked
Linux x86_64 release archive validated across representative Debian, Ubuntu, Arch, Fedora,
openSUSE, Rocky Linux, and Alpine containers. The formal release body is maintained in
`release-notes/v1.0.0.txt`.
