# Tickt keybindings

Tickt is keyboard-first. The footer always shows the most useful controls for the active
view, and modal prompts capture input before the dashboard can receive it.

| Key | Dashboard | Other views |
| --- | --- | --- |
| `Space` | Start, pause, or resume | — |
| `n` | Start the suggested next session | — |
| `b` | Start a short break while idle | — |
| `l` | Start a long break while idle | — |
| `r` | Ask before resetting | — |
| `s` | Ask before skipping | — |
| `h` | Open history | — |
| `t` | Open statistics | — |
| `,` | Open settings | — |
| `?` | Open help | Open help |
| `Esc` / `d` | — | Return to dashboard |
| `j` / `k` | — | Scroll history |
| `q` | Ask before quitting | Ask before quitting |

Confirmation dialogs use `y` or Enter to confirm and `n` or Escape to cancel. Startup recovery
uses `r` to recover an unexpired timer and `d` to record it as interrupted. An expired timer
cannot be counted as completed work.
